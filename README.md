# Tier1Club Practices Examples

This repository contains examples of practices for the Tier1Club community.

## How to use

1. Install [Node.js](https://nodejs.org/en/download/)
2. Install [Bun](https://bun.sh/docs/installation)
3. Run `bun install`
4. Run `bun --filter \"_name_of_your_project_\" _command_` to run the command in your project -- Please refer to the [Bun Filter CLI](https://bun.sh/docs/cli/filter) for more information.
